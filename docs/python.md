## The least snakey snake: Python

Python is the easiest language to learn, as it is the easiest to read and is recommended for beginners.
Python is extremely good at compiling data and making graphs.
Unlike Java, you do not need to declare the type of object to use it.
```python
x = 2
# You can make any variable like this
```
There is no other difference between variables between Java and Python.
Now, let's how to print.
It's as easy as this
```python
print("Hello")
```
You can also print variables themselves to print their values.
Printing the type of variable a variable is is also possible.
Now onto the function, def.
```python
def hello_there():
print("Wazzap")
```
You can choose to make the function return something, like the solved value of an equation.
