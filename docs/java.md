# Java rundown
Java is (in my opinion) the most complicated language to learn.
Java is used very commonly in games such as Minecraft, Runescape, Project Zomboid, etc.
(Learning Java can also help you develop mods for games that use the same language.
Java is very particular about how it is formatted.
**Remember, learning what errors mean is important, as you need to know what is wrong with your code.**

To start, you have to write a main method
```java
public class startThing
{

  public static void main(String[] args)
  {
    System.out.println("Wazzzap!");
  }
}
```
Writing a main method is how you start a Java file, and you cannot run code without it


When you want to make a variable to use later in your code, you have to declare the type of variable it is, then assign it a value. You can also do

```java
boolean declared;
// this is how you declare a variable
declared = true;
// this is how you assign a value
boolean initialize = true;
```
